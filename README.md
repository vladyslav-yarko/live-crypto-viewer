# ₿ Crypto Price Tracker (Child Project of Exchange)

This is a child project focused exclusively on **real-time cryptocurrency price tracking**.  
It provides live crypto market data using external APIs and a fully implemented frontend.

## ✨ Features

- ₿ Real-time prices for **cryptocurrencies**
- 🔌 Integration with third-party crypto APIs  
  - Binance API for live market data
- ⚡ Fast and responsive user interface

## 🛠 Tech Stack

### Backend
- **Python**
- **FastAPI**

### Frontend
- **JavaScript**
- **React.js**
- **Tailwind CSS**

## ✅ Project Status

- Fully working frontend
- No authentication or email verification
- Focused only on crypto-related functionality

## 🎯 Goal

The goal of this child project is to provide a **simple, clean, and fast** interface for tracking cryptocurrency prices in real time, without additional complexity such as authentication or email services.
